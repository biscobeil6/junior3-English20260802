# 中3英語アプリ 英単語2,400語完成版 v2.0

## 今回の追加・修正
- 英単語マスター E00001〜E02400 を例文穴埋め形式で2,400問収録
- 大きな一つの手書き枠へ、例文に必要な語形を書く
- 回答後も筆跡を保持
- 正解語形は例文中で赤字表示し、重複していた単独の正解表示は削除
- 回答後に見出し語・品詞・意味を表示
- ○・△・×、周回、ランダム、苦手復習、履歴、成績リセットへ接続
- 重要英文 SE0001〜SE0500、既存の不規則動詞・熟語試作データを維持

## データ
- `vocabulary_E00001-E02400.json`: 英単語2,400問の単独データ
- `questions.json`: アプリ統合データ（全2,936問）
- `VALIDATION_REPORT.json`: 自動検査結果

## 表記ルール
- 正解はExcel例文中の実際の語形を使用
- 大文字・小文字、ハイフン、アポストロフィーは例文原文を保持
- 見出し語と正解語形は別フィールドで保持
- 元Excelは変更せず、問題化処理はJSON側のみで実施


## v3.0 不規則動詞実データ組み込み
- 完成版マスター IV0001〜IV0077、全77動詞を収録

## v3.1 例文穴埋めレイアウト修正
- 不規則動詞・例文穴埋めの回答後に表示していた「活用・意味」ボックスを削除

- 活用練習画面、全3,066問の問題データ、自己採点・周回・履歴・保存キーは変更なし

## v4.0 熟語・連語実データ組み込み・全4分野完成版
