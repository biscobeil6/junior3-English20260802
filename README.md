# 中3英語アプリ 英単語100語試作版 v1.1

## 今回の追加
- 英単語マスター E00001〜E00100 を例文穴埋め形式で100問収録
- 大きな一つの手書き枠へ、例文に必要な語形を書く
- 回答後も筆跡を保持し、正解・見出し語・品詞・意味を設問直下に表示
- ○・△・×、周回、ランダム、苦手復習、履歴、成績リセットへ接続
- 重要英文 SE0001〜SE0500、既存の不規則動詞・熟語試作データを維持

## データ
- `vocabulary_E00001-E00100.json`: 英単語100問の単独データ
- `questions.json`: アプリ統合データ（全636問）
- `VALIDATION_REPORT.json`: 自動検査結果

## 表記ルール
- 正解はExcel例文中の実際の語形を使用（例: receive → received）
- 大文字・小文字は例文原文を保持
- 見出し語と正解語形が異なる場合は、回答後に見出し語も表示
- 元Excelは変更せず、問題化処理はJSON側のみで実施
