# 中3英語アプリ 試作版 v0.3

## v0.3の修正

- 学習終了ボタンを手書き操作ボタンの横へ移動
- 英単語・不規則動詞例文・熟語連語の未回答部分を「（　　　）」で表示
- 回答後は空欄位置へ正解を赤字表示
- 重要英文・定型表現に、スラッシュ区切りのシャッフル語群を追加
- 重要英文は日本語と語群を見て、英文全体を一つの手書き枠へ記入

`index.html` と `questions.json` は同じフォルダに置き、Webサーバー経由で開いてください。


## v0.3 修正
- 熟語・連語および不規則動詞例文で、正解語数と同じ数の空欄を表示します。
- 不規則動詞の活用問題を「原形・過去形・過去分詞」の一行表示に変更しました。


## v0.4 重要英文試作

- 表示用語句では句読点を除外し、短縮形・ハイフン語・数字・時刻は一語として保持
